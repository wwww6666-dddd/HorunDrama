# 代码签名（Horun）

> 2.0.1 起产物使用 `CN=Horun, O=Horun, C=CN` 的 Authenticode 证书签名。
> **当前是自签名证书**：本机安装 `docs/horun-codesign.cer` 后签名有效、发布者显示 Horun；
> 其他用户未安装证书时 SmartScreen 仍会提示“未知发布者”，这是自签名证书的固有限制。
> 要彻底消除提示，需要购买受信任 CA 的代码签名证书（约 $100~$400/年），把 PFX 换掉即可。
>
> **为什么别的一些播放器不签名也不弹**：从 zip 解压出来、或本机自己编译的 exe 没有
> `Zone.Identifier`（Mark-of-the-Web），SmartScreen 主要拦截"浏览器直接下载且带 MOTW"的 exe。
> 分发建议：优先给绿色包，用 7-Zip 解压后运行；安装包下载后右键 → 属性 → 勾选"解除锁定"
> （或 `Unblock-File`）再运行，通常就不会再弹。**不要**在程序里写绕过 SmartScreen 的代码。

## 私钥 / 公钥

| 文件 | 说明 | 是否入库 |
|---|---|---|
| `certs/horun-codesign.pfx` | 含私钥，签名用 | **否**（`.gitignore` 已忽略） |
| `certs/horun-codesign.cer` | 公钥，给用户导入信任 | 复制到 `docs/horun-codesign.cer` 后入库 |
| PFX 密码 | 环境变量 `HORUN_CSC_PASSWORD` | 否 |

## 签名步骤（每次发版）

```powershell
# 1) 只打 win-unpacked（不要直接 dist，dist 里的安装包会先嵌入未签名 exe）
$env:NODE_TLS_REJECT_UNAUTHORIZED='0'; $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
pnpm --filter @horun/desktop run pack

# 2) 签 win-unpacked 里的两个 exe（launcher + core）
$env:HORUN_CSC_PASSWORD = '<你的 PFX 密码>'
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/scripts/sign-release.ps1 -Version 2.0.1

# 3) 用已签名的 win-unpacked 生成安装包（不会再重新打包 app）
pnpm --filter @horun/desktop exec electron-builder --win nsis --prepackaged release/win-unpacked

# 4) 再签安装包本身（脚本会顺带重签两个 exe，没问题）
powershell -NoProfile -ExecutionPolicy Bypass -File apps/desktop/scripts/sign-release.ps1 -Version 2.0.1

# 5) 最后打绿色包，确保 zip 里的 exe 也是签过名的
Set-Content apps/desktop/release/win-unpacked/portable.txt 'portable' -Encoding ASCII
Copy-Item apps/desktop/resources/使用说明.txt apps/desktop/release/win-unpacked/ -Force
tar -a -c -f apps/desktop/release/HorunDrama-2.0.1-win64-portable.zip -C apps/desktop/release/win-unpacked .
```

> 顺序非常重要：**先 pack → 签 exe → prepackaged 出 nsis → 签安装包 → 再 zip**。
> 如果先 `dist` 再签，安装包内部的 exe 仍是未签名版本（2.0.1 踩过）。
> 也可以用 `CSC_LINK`/`CSC_KEY_PASSWORD` 让 electron-builder 打包时自动签，但本机实测
> 自签名 PFX 在该流程里会卡在签名阶段，所以最终采用上面的“先 dir 后 prepackaged”流程。

## 本机导入证书

```powershell
certutil -user -addstore Root docs/horun-codesign.cer
certutil -user -addstore TrustedPublisher docs/horun-codesign.cer
Get-AuthenticodeSignature 'apps/desktop/release/win-unpacked/HorunDramaCore.exe'
# Status 应为 Valid，Signer 为 CN=Horun, O=Horun, C=CN
```

## 自动更新与签名

自动更新下载的是绿色包（`HorunDrama-<版本>-win64-portable.zip`），里面已包含签名后的
`HorunDrama.exe` / `HorunDramaCore.exe`。解压覆盖后签名仍然有效；不会因为更新变成未签名版本。
