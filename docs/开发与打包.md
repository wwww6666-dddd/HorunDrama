# 开发与打包

给想改代码 / 自己编译的人看。**普通用户不需要看这个**，去
[Releases](https://github.com/wwww6666-dddd/HorunDrama/releases) 下载现成的就行。

## 环境

- Node.js ≥ 22.6（核心直接用 `node` 跑 `.ts`，不经过编译）
- pnpm 12.18+（`packageManager` 已写死版本）
- Windows 10/11 x64（打包目标）
- 打包还需要系统自带 .NET Framework 的 `csc.exe`（编译 C# 启动器）

```bash
pnpm install
pnpm dev      # 核心 + 前端一起跑（Vite 代理 /api）
pnpm build    # 只构建前端
pnpm start    # 只跑核心，http://127.0.0.1:5880
pnpm -r --parallel run typecheck   # core + web + desktop 类型检查
```

数据目录默认 `%APPDATA%\HorunDrama`，可用 `HORUN_DATA_DIR` 覆盖。

## 目录

```
apps/
├ core/       无头核心（Node/TS + node:sqlite）：取流/转码、目录/搜索/榜单、进度/收藏、设置、图片代理
├ web-next/   前端（Vite + React + zustand）：设计系统、页面、播放器封装
└ desktop/    Electron 壳：窗口、启动器、单实例、拉起核心、打包配置
docs/         开发文档
scripts/      开发脚本
```

渲染进程只通过 `/api/*` 与核心通信；主进程只管窗口与系统能力。

## 打包前要自备的运行时资源

这些二进制**不进仓库**（体积大、且有各自的许可证），但**打包时会一起塞进安装包**，
所以最终用户拿到后不需要再装任何东西：

| 资源 | 放在 | 说明 |
|---|---|---|
| `ffmpeg.exe` | `apps/desktop/resources/ffmpeg/` | 转码 / 解密。用你自己编译或发行版都行 |
| `hgsigner.exe` | `apps/desktop/resources/hgsigner/` | 本地签名服务（`127.0.0.1:8791`）。**没有它账号接口不可用，播放不受影响** |

`openhongguo`（内容 SDK，WASM）是 npm 依赖，`pnpm install` 时装好；
`apps/desktop/scripts/prepare-vendor.mjs` 会在打包前把它实体化到 `vendor/`，
再由 `package.json` 的 `extraResources` 放进安装包的 `resources/core/node_modules/`。

## 出包

```bash
pnpm build

cd apps/desktop
node scripts/prepare-vendor.mjs
node scripts/build-launcher.mjs           # 编译 C# 启动器

# 1) 只打 win-unpacked（先不要 nsis，否则安装包里会嵌入未签名 exe）
pnpm exec electron-builder --win --dir

# 2) 签名两个 exe（需要 certs/horun-codesign.pfx + HORUN_CSC_PASSWORD）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\sign-release.ps1 -Version x.y.z

# 3) 用已签名的 win-unpacked 出安装包
pnpm exec electron-builder --win nsis --prepackaged release/win-unpacked

# 4) 再签安装包
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\sign-release.ps1 -Version x.y.z

# 5) 绿色版（必须在签名之后）
echo portable > release\win-unpacked\portable.txt
copy resources\使用说明.txt release\win-unpacked\
tar -a -c -f release\HorunDrama-x.y.z-win64-portable.zip -C release\win-unpacked .
```

> 签名顺序详见 [代码签名](代码签名.md)。

`win-unpacked` 里有 `portable.txt` 时，程序会把数据写在 exe 同目录的 `data\`（便携模式）。

> 这台开发机连 GitHub 下 Electron 会卡死：先把 `electron-v45.3.2-win32-x64.zip` 放进
> `%LOCALAPPDATA%\electron\Cache`，并设 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。

## 发版

```bash
# 1) 改 apps/desktop/package.json 的 version（关于页显示的版本号也来自这里）
# 2) 构建 + 打包（上面那套）
gh release create vX.Y.Z "release/HorunDrama Setup X.Y.Z.exe" \
  "release/HorunDrama-X.Y.Z-win64-portable.zip" -R <owner>/<repo> --title "HorunDrama X.Y.Z" --notes "…"
```

带 `-R` 很重要：本机的工作仓库没有配置 remote，不带 `-R` 会报 `no git remotes found`。

发版前建议再跑：

```bash
pnpm -r --parallel run typecheck
pnpm --filter @horun/web-next run build
pnpm audit --registry=https://registry.npmjs.org
node .tmp/license-scan.mjs   # 本机脚本，输出 318 个依赖的许可证
```

2.0.0 的审计结论见 [第三方许可与安全审计](第三方许可与安全审计.md)。

## 分享链接格式

红果官方分享链接里：`video_id` = 剧（book）、`vid` / `share_toast_vid` = 分集，
**没有** `book_id`；只有老式链接才是 `book_id`=剧 + `video_id`=集。
我们生成的链接按官方参数来，额外挂 `no`（集号）/ `t`（秒），红果网页会忽略这两个参数。
解析逻辑在 `apps/web-next/src/share.ts`，改之前拿一条真实链接跑一遍。
