## 三、字体

- 项目**没有自带字体文件**（`public/` 只有 icon 与打赏二维码；`design/tokens.css` 只引用系统字体）。
- 字体栈：`Microsoft YaHei / PingFang SC / Noto Sans SC / system-ui` 与
  `Songti SC / Source Han Serif SC / Noto Serif SC`，均为操作系统自带或系统可选字体，
  不随安装包分发，**不存在字体侵权与包体积问题**。
- 如果以后要内置字体，必须选 SIL OFL / Apache-2.0 等可商用字体，并在 `NOTICE.md` 记录。

## 四、漏洞扫描

```
pnpm audit --registry=https://registry.npmjs.org
```

结果（2026-11-19）：

| 严重度 | 数量 | 说明 |
|---|---:|---|
| critical | 0 | — |
| high | 0 | — |
| moderate | 1 | `minimatch` ReDoS/DoS（GHSA-g3hv-75wg-m249），仅存在于 **electron-builder 开发依赖**，不进入安装包运行时 |
| low | 0 | — |

- 默认镜像 `registry.npmmirror.com` 没有实现 audit 接口（`ERR_PNPM_AUDIT_ENDPOINT_NOT_EXISTS`），
  所以用官方 registry 跑；以后 CI 里固定加 `--registry=https://registry.npmjs.org`。
- `minimatch` 只用于打包工具解析 glob，不接收不可信输入；升级 electron-builder 时会被动带上去，
  不建议为它强行 override（会破坏 electron-builder 的依赖树）。

## 五、应用自身的安全检查

- 本地 core 默认只监听 `127.0.0.1`，不对局域网开放。
- 渲染进程只走 `/api/*`，不直接读文件；`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`。
- 外链统一 `shell.openExternal`，只放行 `http/https`；渲染进程不直接 `location.href = 外链`。
- 删除废弃 `/api/meta`（早期占位数据，无鉴权、无用途）。
- 账号 Cookie/设备只落本地 `data/`；安装包不包含 `data/`。
- 未签名安装包：SmartScreen 会提示未知发布者，属于预期，不是漏洞。
