# HorunDrama

Windows 短剧播放器。**下载就能用，不需要另外装任何东西**。

![HorunDrama](红果短剧PC版.png)

## 下载与使用（三步）

1. 打开 **[Releases](https://github.com/wwww6666-dddd/HorunDrama/releases)**，按喜好下一种：
   - **安装版**：`HorunDrama Setup x.y.z.exe` → 双击，等它装完
   - **绿色版**：`HorunDrama-x.y.z-win64-portable.zip` → 解压到任意文件夹 → 双击里面的 `HorunDrama.exe`
     （可以整个文件夹搬走、拷到 U 盘，卸载就是删文件夹）
2. 第一次启动会解包资源，等十几秒
3. 就这些，直接开始看

> 系统要求：Windows 10 / 11（64 位）。
> 安装包没有数字签名，首次运行 SmartScreen 会提示「未知发布者」→ 点「更多信息」→「仍要运行」即可。
> 个别杀软会误报，加白名单就行。

## 功能

- **找剧**：推荐流、剧场、新剧、榜单、分类、搜索、追剧
- **看剧**：1080p 优先（上游没有就自动降级）、倍速、清晰度手动切换、全屏、画中画、弹幕
- **进度条能拖**：每集会先准备好完整文件再播，时长准确，想拖到哪就拖到哪
- **自动连播**：播完自动下一集；前后各 5 集会在你看的时候提前准备好
- **分享续播**：别人发来的红果分享链接，粘进软件就能接着看（会先弹一张卡片告诉你这是哪部剧、第几集、从哪开始）
- **账号**：手机号登录、追更/收藏/历史同步、评论与点赞
- **播放器设置**：进度条上的「⚙ 设置」可调清晰度、倍速、弹幕（透明度/字号/颜色/显示区域）、
  自动连播、跳过片头/片尾
- **推荐页沉浸布局（2.0.0）**：视频按真实比例居中，左侧片单随切换平滑滚动，控制条贴着画面
- **自动更新（2.0.1）**：启动后自动检查新版本，后台下载，点“立即重启更新”自动覆盖并重启；
  更新完全自愿，打赏也完全自愿
- **更顺手的手感（2.0.1）**：卡片大封面 3D 倾斜 / 跟随光斑、顶部华为式透明玻璃光感

## 数据放在哪

| 版本 | 数据目录 |
|---|---|
| 安装版 | `%APPDATA%\HorunDrama` |
| 绿色版 | `HorunDrama.exe` 同目录的 `data\` |

占空间了：设置 → 缓存 → 清空。遇到打不开/白屏：删掉上面那个数据目录再启动一次。

## 更新与反馈

- 自动更新提示：启动后会自动检查；也可以在设置 → 关于 →「检查更新」手动查
- 更新说明 / 下载：GitHub Releases（更新卡片和关于页都有入口）
- 提问题 / 提需求：顶栏「✎」直接打开 Issues，或
  [新建 issue](https://github.com/wwww6666-dddd/HorunDrama/issues/new)
