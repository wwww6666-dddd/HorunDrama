# HorunDrama · 使用说明

个人维护的 Windows 短剧客户端。提供两种形式：**安装版** 和 **绿色压缩包版**。

## 运行要求

- Windows 10 / 11（64 位）

## 安装版

双击 `HorunDrama Setup 2.0.6.exe` → 一键安装，装完从开始菜单之外的位置找
`%LOCALAPPDATA%\Programs\HorunDrama\HorunDrama.exe`（可以直接在文件管理器地址栏粘贴）。

数据目录：`%APPDATA%\HorunDrama`（设置、登录、视频缓存都在这里）。

## 绿色压缩包版（推荐发给别人）

1. 把 `HorunDrama-2.0.6-win64-portable.zip` **解压到任意文件夹**；
2. 双击里面的 `HorunDrama.exe`。

压缩包里带 `portable.txt`，程序会自动把数据写在 **exe 同目录的 `data\`** 下，
整个文件夹可以随意搬迁、拷到 U 盘，卸载就是删文件夹。

> 注意：不要把 `HorunDrama.exe` 单独拖出来运行，它依赖同目录的 `resources\`。

## 首次启动

- 第一次启动要解包资源，等十几秒，之后就快了
- 默认清晰度 1080p：没缓存时会先**等这一集转好再播**（转码期间显示进度），
  这样进度条有完整时长、能直接拖；之后的集会在后台预加载，基本不用再等
- 想调清晰度/画质增强/预加载集数：设置 → 画质与下载

## 分享与续播

- 播放页右侧「分享」→ 复制的是**红果原链接**（另带 `no`/`t` 记录看到第几集第几秒）
- 顶栏「分享续播」→ 把别人发的红果分享链接粘进来 → 会先弹一张卡片
  （哪部剧、第几集、共几集、从哪开始），点「开始观看」才跳过去

## 更新与反馈

- 自动更新提示：启动后会自动检查新版本，弹卡片说明更新内容并给下载链接（自愿更新）
- 手动检查：设置 → 关于 → 「检查更新」，或直接看 GitHub Releases
- 问题反馈：顶栏「✎」直接打开 GitHub Issues

## 常见问题

- **打开失败 / 白屏**：删掉数据目录（安装版 `%APPDATA%\HorunDrama`，绿色版 `data\`）再启动
- **高清时好时坏**：上游接口有软限流，程序会自动重试并缓存，看过的集之后都是秒开
- **占空间**：设置里可改缓存上限（默认 4GB）或一键清缓存
- **杀软报毒 / 未知发布者**：程序已用自签名证书签名（发布者显示 Horun），但 Windows 仍可能
  提示「未知发布者」；个别杀软会误报，加白名单即可
